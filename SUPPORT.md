# Address Atlas Support

Address Atlas is a local-first, read-only portfolio viewer for macOS and iOS. For help, bug reports, or privacy questions:

- Email [girginomer10@gmail.com](mailto:girginomer10@gmail.com).
- Open a [public support issue](https://github.com/girginomer10/address-atlas/issues/new/choose) only if the report contains nothing sensitive.
- Report suspected security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/girginomer10/address-atlas/security/advisories/new).

Never put wallet inventories, exchange API keys, session tokens, recovery files or codes, private keys, seed phrases, or raw production logs in a public issue. Address Atlas cannot recover funds, reverse transactions, or give investment advice.

## Reporting a bug

Include:

- the Address Atlas version
- the macOS or iOS version and the device
- the screen where it happened
- what you expected
- the privacy-safe diagnostic summary in **Settings**

Replies are best-effort. There is no guaranteed service-level agreement.

## iCloud transfers

Use the same Apple Account on both devices (Mac, iPhone, or iPad), and turn on Passwords & Keychain on both. Transfers are manual, from **iCloud**. The encryption key can arrive after the portfolio copy. If it is missing, wait and try again instead of deleting anything.

The maintainer cannot recover an iCloud encryption key. A recovery kit protects the local portfolio key, not the separate iCloud key. See [iCloud setup and limitations](docs/ICLOUD.md).
